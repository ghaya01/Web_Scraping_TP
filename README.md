# TP01: Python Web Scraping Case-Study (Quotes Scraper)

This project is a Python-based web scraper that extracts quotes from **Wikiquote** using its MediaWiki API. The collected data is parsed, processed, and stored in a clean CSV file.

## ⚙️ Requirements

Ensure you have Python 3.x installed along with the required libraries:

* **Python 3.x**
* **requests** (for fetching web contents via API)
* **beautifulsoup4** (for parsing HTML structure)
* **pandas** (for data processing and exporting to CSV)

To install all dependencies, run the following command in your terminal:

```bash
pip install requests beautifulsoup4 pandas
